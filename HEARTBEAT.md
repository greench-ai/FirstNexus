# HEARTBEAT.md

Do not reply HEARTBEAT_OK every time. Use heartbeats productively.

## Periodic Checks (rotate through — 2-4x daily)

- **Email** — any urgent unread messages?
- **Calendar** — upcoming events in next 24-48h?
- **NexusClaw status** — is the gateway running? `nexusclaw gateway status`

## When to Reach Out
- Gateway is down
- Important email arrived
- Calendar event in <2h
- Nothing new since last check

## When to Stay Quiet
- Late night (23:00-08:00) unless urgent
- Nothing new since last check
- Just checked <30 min ago
